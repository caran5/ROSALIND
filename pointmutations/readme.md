a mutation is a mistake during the creation or copying or a nucleic acid - which have the opportunity to cause a ripple effect throughout the cell. the simplest and most common one is a point mutation which replaces one base with another at a single nucleotide. 

two dna strands taken from different organisms or species genomes are homologous if they share a recent ancestor; thus, counting the number of bases at which homologous strands differ provide us with the minimum number of point mutations that culd have occured on the evolutionary path between the two strands. 

we are interested in minimzing the number of point mutations seperating two species because of the biological principle of parsimony which demands that evolutionary histories should be as simply explained as possible
